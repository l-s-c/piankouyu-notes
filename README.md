# 偏口鱼博士的直播笔记

**简体中文** · [English](README.en.md)

这是一份独立整理的中文资料库，记录偏口鱼博士（鱼博）在公开直播和短视频里怎样回答观众。整场笔记保留提问的顺序，知识章节把不同场次谈到的同一件事放在一起。读者可以查一道题的答案，也可以点时间回到原片，听听观众补了什么条件，他为什么改口。

**第一次来，可以从一个椰子读起。** 鱼博说椰子水贵，海南观众不服。他接着举例，五块钱买一颗解馋，他能理解。二三十块钱一颗，还拿美白当卖点，他就不愿为这个理由加价。整场笔记留下这次追问，选购章节则借它讨论买椰子时，哪部分钱花在口味上，哪部分花在宣传的功效上。[读这段问答并回看原片](sessions/2026-10-31.md#at-1522) · [读选购笔记](knowledge/shopping.md#coconut-price)

## 安装到 Codex

`piankouyu` 是本项目的独立 Skill，安装包里带有问答、知识章节和表达风格笔记。把下面一行粘贴到 **Codex 对话框**，即可安装。[查看 Skill 目录](skills/piankouyu/)

```text
$skill-installer 请从 https://github.com/l-s-c/piankouyu-notes/tree/main/skills/piankouyu 安装这个 Skill
```

安装完成后，下一条消息就可以这样问。Skill 会用第一人称转述鱼博当时的回答，并附上回放时间点。

```text
$piankouyu 鱼博怎么看豆腐当主食？把 9 月和 10 月两次回答放在一起，给我原片时间点。
```

**手动安装（已有仓库副本）**　在 macOS 或 Linux 上，打开终端进入仓库根目录，运行下面两行。目标已有同名 Skill 时，命令会保留现有目录。

```sh
piankouyu_dir="${CODEX_HOME:-$HOME/.codex}/skills"
mkdir -p "$piankouyu_dir" && test ! -e "$piankouyu_dir/piankouyu" && cp -R skills/piankouyu "$piankouyu_dir/"
```

如果安装器提示已有同名目录，先把它显示的旧 `piankouyu` 文件夹移到 Skills 目录之外备份，再发送安装指令。

## 笔记怎么写，怎么补

问答用**第一人称按原意转述**。整场页标明哪些问题能听到鱼博念出来，哪些根据接话还原。需要逐字核对时，点每条旁边的时间。健康话题里，整理者补查的指南或纠正意见单列为**编注**。

补充材料或纠错时，请附作品链接、片内时间和想改的那句话。同一个问题在另一场有不同回答，也欢迎把两段一起贴出，好核对当时换了什么条件。资料整理的写法另有记录。[人物 Skill 的编写参考](editing/persona-references.md)

维护者修改问答或知识章节后，请在仓库根目录运行 `python3 tools/sync-skill-references.py` 更新 Skill 的离线副本。提交前可加 `--check` 检查是否同步。
