# 偏口鱼博士的直播笔记

**给家里人补蛋白，要不要买海参？** 鱼博的答案是：买鸡蛋就行，不用为补蛋白专门买海参。海参在他的三国比方里还是名将，只不过鸡蛋是关羽。这个比方最后落在了两件实事上：鸡蛋能提供蛋白质，还便宜。家里人就爱吃海参，过节买来做道菜，那花的是喜欢这口的钱。[海参与鸡蛋的直播切片](https://www.douyin.com/video/7624116410029914515)

这份笔记收录他在直播和公开视频里给过的答案。下面是观点转述，点进章节能看到原来的提问、理由和出处。

| 你想知道的事 | 答案先看这里 |
| --- | --- |
| 超市称重沙拉怎样配成一顿饭？ | **菜、主食和蛋白质都装进去。** 看他在直播里怎样分餐盘，再看他本人拿饭盒去夹什么。[超市选购与餐盘](knowledge/shopping.md) |
| 减重还用运动吗？ | **谈长期减重，他给了力量训练和快走两个选项。** 在一条题为“减肥不需要运动”的剪辑里，这些话就在 20 分 44 秒之后。[运动与训练](knowledge/exercise.md) |
| 上学的孩子只喝豆浆、吃鸡蛋，早餐够吗？ | **按他的搭配，还要加主食。** 比如留份全麦面包。鸡蛋解决了蛋白质的问题，没包办整顿早餐。[餐桌上的营养](knowledge/food.md) |
| 不吃晚饭，怎么体重还没降？ | **少一顿不等于全天吃得少。** 先把早饭、午饭、奶茶和零食算进去，看省下的那顿有没有在别处补回来。[分量、做法和频率](knowledge/habits.md) |
| 蜂蜜水能润肺、抗老吗？ | **想喝甜的可以喝，别为这两个功效买。** 他认可蜂蜜的甜味，没给它润肺、抗老的本事背书。[食物与健康承诺](knowledge/claims.md) |
| 喝点红酒就困，算睡得好吗？ | **不算，也别靠酒入睡。** 喝完很快犯困，不能说明后半夜睡得好、第二天有精神。[睡眠与休息](knowledge/sleep.md) |
| 六级单词每天都背，还是忘怎么办？ | **把昨天忘的词排进今天，再上新词。** 遇到动词，换个例句，看还能不能认出它的变形、读懂它的意思。[学习与科研](knowledge/research.md) |
