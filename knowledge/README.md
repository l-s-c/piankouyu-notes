# 知识体系：他拿什么作比较

同一颗鸡蛋，在这些直播里扮过三种角色：跟海参比，它是普通人买得到的蛋白质来源；有人问怎么养肺，他又用鸡蛋说明，再好的食物也没有“专门养哪个器官”的本事；有人想吃蛋壳补钙，他干脆把问题换成牛奶和其他日常钙来源。只记“他推鸡蛋”，这三个回答就互相打架。把每次要解决的事写清楚，关系就出来了。[海参与鸡蛋](https://www.douyin.com/video/7624116410029914515) · [吃什么养肺](https://www.douyin.com/video/7663443810148171658) · [芝麻、蛋壳和牛奶，07:47](https://www.bilibili.com/video/BV1q2XjB6EB9/?t=467)

以下是整理者根据这些问答重建的框架。它能帮助理解他已说过的话，也标得出哪些地方还需要证据。

| 看问题的角度 | 直播里最能说明它的一对例子 | 推到哪里就该停 |
| --- | --- | --- |
| **目的决定比较对象** | 补蛋白，他比海参和鸡蛋；补钙，他把芝麻和奶放在一起。换一个目标，参照物也换。[餐桌上的营养](food.md) | 好吃、送礼、能吃得下，都是另外的购买理由。一个营养指标排不出“所有食物总榜”。 |
| **实际吃法决定这一餐** | 一根玉米和磨成粉的玉米粥；两顿正餐加奶茶、零食和通常的三餐。[分量、做法和频率](habits.md) | 听清一天吃多少、做得多细、和什么一起吃。只凭名字算不出某个人的餐后血糖。 |
| **食物成分、身体感受和疾病结局要分别举证** | 酸奶里加了多少糖可以看配料；泡脚舒服是体验；“洋葱防癌”是另一个需要证据的承诺。[健康承诺](claims.md) | 食物里有某种成分，不能单凭这一点给出防病、治疗或提分结论。 |
| **把能改变的生活条件找出来** | 问养肺，他追问烟草暴露；问跑不动怎么办，他给快走这个选项。[日常习惯](habits.md) · [睡眠与休息](sleep.md) · [风险与防病](claims.md) | 距离、速度、食品品牌和直播商品编号都有具体语境。应用到个人要再看条件。 |
| **把个人经历留在原来的范围内** | 他先说博士主要靠自己做研究，随后举出自己上过的课程。[科研与个人经验](research.md) | 一个人的口味、项目或生活经验，不能直接代表一个国家、一所学校或一类人。 |

## 按问题串起章节

1. **买什么、怎么吃**：[蛋白质和钙的日常来源](food.md) → [一餐的做法和一天的分量](habits.md) → [如何看待商家的功效承诺](claims.md)。
2. **身体有什么感受**：[运动、咖啡和泡脚](habits.md) → [入睡、恢复感与打鼾](sleep.md)。舒服、困倦和睡得好要分别讨论。
3. **学习怎样看见进步**：[从课程、词表到真实任务](research.md)。和算一天吃了多少类似，他先把目标拆到可以核对的一件件事上。

## 两条线索，贯穿全书

**从一顿饭走到一天。** 在超市看一瓶酸奶，可以先看里面是什么、自己能不能耐受；放到早餐里，要看它和主食、其他食物怎么搭；放到全天，还要看饮料和零食有没有漏算。三个尺度解决的是不同问题。[选奶](food.md) · [全天摄入](habits.md)

**从一句狠话走回提问。** “少喝粥”要回到那碗粥，“不如鸡蛋”要回到买海参的目的，“粑粑”也要回到他说的是哪样东西。写知识正文时保留对象和理由；还原直播里的笑点时，把半句话前后的追问放回来。[直播问答](../dialogues.md) · [表达风格](../voice.md)
